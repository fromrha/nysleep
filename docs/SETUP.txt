NYTHSLEEP - GLOBAL CLI SETUP
=============================

Supported: Windows 10/11, Linux distributions using systemd, macOS.
Requires Python 3.9+ and pipx.

INSTALL
-------

From a clone:

    pipx install . --force
    pipx ensurepath

From GitHub:

    pipx install git+https://github.com/fromrha/nythsleep.git
    pipx ensurepath

`pipx ensurepath` automatically adds pipx executable directory to current user
PATH. Close and reopen terminal after running it. Then commands work globally:

    nythsleep --help
    nsleep --version

CACHYOS / ARCH NOTIFICATIONS
----------------------------

    sudo pacman -S libnotify python-pipx

`loginctl` and `systemd-inhibit` come from systemd and provide Linux power and
Keep Awake integration. Nythsleep is not tied to KDE; any active graphical
systemd session works.

USAGE
-----

    nythsleep
    nythsleep --sleep --timer 30m
    nythsleep --shutdown --battery 15
    nythsleep --insomnia --timer 2h
    nythsleep --restart --yes

Power actions prompt by default. `--yes` skips prompt for deliberate unattended
scripts. Ctrl+C cancels countdowns and battery waits.

LEGACY WINDOWS WRAPPERS
-----------------------

`nythsleep.bat` and `nsleep.bat` remain for clone-based Windows use. New installs
should prefer pipx because it exposes both commands globally on every OS.
